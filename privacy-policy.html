Politique de Confidentialité de Nafar AI

Version 1.0 – Mis à jour le 04/04/2025

1. Qui sommes-nous ?

Nafar AI est une application éducative développée par Nafar AI, dont le siège social est situé à Dakar. Notre objectif est de vous aider à apprendre efficacement grâce à des outils personnalisés comme des résumés, QCM et évaluations.

  • Site web : www.nafarai.com
  • E-mail de contact : hello@nafarai.com
2. Données personnelles collectées

Nous collectons uniquement les données strictement nécessaires pour personnaliser votre expérience. Ces données incluent :

  • Informations d'inscription :
    • Nom et prénom.
    • Âge (pour adapter les contenus à votre niveau).
    • Nom de l'école et classe (pour contextualiser les révisions).
    • E-mail (pour les notifications et support).
    • Numéro de téléphone (facultatif, pour les communications urgentes).
  • Contenu des cours scannés :
    • Le texte extrait des photos des cours est utilisé temporairement pour générer du contenu (résumés, QCM, évaluations). Les photos ne sont pas conservées.
3. Pourquoi collectons-nous ces données ?

Vos données sont utilisées dans les buts suivants :

  • Personnalisation : Adapter les résumés, QCM et évaluations à votre niveau, matière et établissement.
  • Amélioration du service : Utiliser les données anonymisées pour entraîner notre modèle IA afin de fournir un contenu de meilleure qualité.
  • Communication : Vous informer des mises à jour ou répondre à vos demandes via l'e-mail ou le numéro de téléphone fourni.
4. Partage des données

Nous ne vendons pas vos données. Elles peuvent être partagées dans les cas suivants :

  • Fournisseurs techniques : Nous utilisons Firebase pour stocker et sécuriser vos données. Ces partenaires s'engagent à protéger vos informations.
  • Établissements scolaires (futur) : Si vous utilisez Nafar AI dans le cadre d'un partenariat avec une école, certaines données pédagogiques pourront être partagées avec eux (ex : résultats d'évaluations).
  • Obligations légales : En cas de demande judiciaire ou administrative.
5. Stockage et sécurité des données
  • Stockage : Vos données sont hébergées sur Firebase, une plateforme sécurisée qui garantit la protection de vos informations.
  • Durée de conservation : Les données personnelles sont conservées uniquement pendant que vous utilisez l'application. Si vous supprimez votre compte, toutes vos données seront effacées immédiatement.
  • Sécurité : Nous utilisons les mesures de sécurité fournies par Firebase, notamment le chiffrement des données sensibles et l'accès restreint aux administrateurs.
6. Vos droits

Conformément aux lois applicables, vous disposez des droits suivants :

  • Accès : Vous pouvez demander une copie de vos données personnelles.
  • Modification : Mettre à jour vos informations (ex : nom, âge, école).
  • Suppression : Supprimer votre compte et vos données définitivement.
  • Opposition : Refuser que vos données soient utilisées à des fins spécifiques.

Pour exercer ces droits, contactez notre équipe de support à hello@nafarai.com. Nous répondrons dans un délai de 7 jours.

7. Public cible
  • Actuellement : L'application est destinée aux élèves et étudiants capables d'utiliser l'application pour leurs études.
  • Mineurs : Nous acceptons les mineurs, mais nous recommandons un accord parental pour les utilisateurs de moins de 16 ans.
8. Déploiement futur

Bien que l'application soit actuellement développée principalement pour le Sénégal, nous prévoyons de l'étendre à d'autres pays dans le futur. Cette politique sera mise à jour en conséquence.

9. Modifications de la politique

Cette politique peut être modifiée pour refléter des changements dans nos pratiques ou pour se conformer à de nouvelles réglementations. Les modifications seront publiées ici et signalées via l'application.

10. Contact

Pour toute question ou réclamation concernant cette politique de confidentialité, contactez-nous :

  • E-mail : hello@nafarai.com
  • Adresse physique : Dakar, Sicap kara
